# Smart Community Problem Solver

This repository contains the starter code for the Smart Community Problem Solver hackathon project.

MVP: User opens the website, submits a problem (title, description, location), backend receives it, saves to MongoDB, and the dashboard lists reported problems.

Folders:
- backend/ — Express API, MongoDB (Mongoose)
- frontend/ — React (Vite) app

Follow the step-by-step instructions in the repo README to run the project locally.
